# 📁 Сканер папок

Программа на Python с графическим интерфейсом для сканирования папок и дисков.

## Возможности

- Сканирование любой папки или диска
- Показывает общее количество файлов и папок
- Топ-5 самых больших файлов
- Свободное место на диске (при сканировании диска)
- Игнорирование системных папок (Windows, Program Files и т.д.)
- Две круговые диаграммы: распределение по папкам и расширениям
- Сохранение отчёта в `report.txt`

## Как запустить

### Для обычных пользователей
Скачай `FolderScanner.exe` из раздела **Releases** и запусти.

### Для разработчиков
```bash
pip install PyQt6
python scanner.py
