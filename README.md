# folder-scanner
Сканер папок на Python с прогресс-баром и топ-5 самых больших файлов

Программа на Python, которая сканирует папку и показывает:
- Общее количество файлов
- Общий размер
- Топ-5 самых больших файлов
- Прогресс-бар в процессе сканирования
- Сохранение отчёта в `report.txt`

## Как запустить

1. Скачай файл `scanner.py`
2. Запусти в терминале:
   ```bash
   
   python scanner.py
   
3. Введи путь к папке (например, C:\Users\Yoki\Documents)
