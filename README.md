# Сканер папок 📁

Программа на Python для сканирования папок и анализа файлов.

## Как запустить

1. Скачай `scanner.py` из раздела **Releases**.
2. Перемести файл в папку, где есть права на запись (например, на рабочий стол или в `Documents`).
3. Запусти двойным кликом или через терминал:
   ```bash
   python scanner.py
4. Введи путь к папке и жди результат.

## Важно

Если при сохранении отчёта появляется ошибка "нет прав на запись":

Перемести scanner.py в другую папку (например, на рабочий стол)

Или запусти от имени администратора
